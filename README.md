# Java GUI Learning Projects
This repository contains a collection of simple Java GUI applications developed while learning and practicing graphical user interface development.

## Projects

The repository includes simple GUI programs such as:

- Simple Calculator
- GCD, Integer Division, Factorial Calculators
- Key and Mouse Events
- Other Java GUI practice programs

## Technologies Used

- Java
- Java Swing
- Java AWT

## Purpose

The purpose of this repository is to practice Java GUI concepts and develop a better understanding of creating interactive desktop applications.

## How to Run

1. Clone or download this repository.
2. Open the Java project in a Java-supported IDE such as VS Code, IntelliJ IDEA, Eclipse, or NetBeans.
3. Compile and run the required `.java` file.

## Note

These programs are created primarily for learning and practice purposes.
